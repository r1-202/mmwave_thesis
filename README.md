# 5G mmWave Attenuation — ML Prediction & Optimization
**MSc Thesis · Lebanese International University (LIU) · 2025**
Ibrahim Mahmoud Abdelghani · Mohammad Khaled Moussa

A complete AI research system that predicts and optimizes weather-induced
attenuation on a 38 GHz 5G mmWave link, trained on **512,944 rows of real
measured attenuation** (CoMMon CML campaign).

## What's inside

```
mmwave_thesis/
├── data/                              # ~48 MB real CoMMon dataset
├── results/
│   ├── index.html                     # ★ Interactive HTML dashboard (open in any browser)
│   ├── dashboard_data.json            # All data feeding the dashboard
│   ├── ml_results.json                # ML model metrics (RMSE/R²/MAE/latency)
│   ├── kpis.json                      # Link-budget KPIs from the real data
│   └── plotly.min.js                  # Bundled for offline use
├── src/
│   ├── models/
│   │   ├── traditional.py             # ITU-R P.838-3 (rain) + P.676 (gases) + Crane (1980)
│   │   ├── ml_models.py               # RandomForest, XGBoost, LightGBM, GBM, SVR, Stacking
│   │   └── beamforming.py             # 8×8 planar-array hybrid BF
│   ├── simulation/
│   │   └── link_simulation.py         # Link budget · SE · BER (QPSK)
│   ├── preprocessing.py               # Feature engineering & temporal train/test split
│   ├── data_loader.py                 # Reads only the weather cols (fast)
│   └── visualization/
│       ├── template.html              # New dashboard markup (~26 KB)
│       ├── charts.js                  # All 27 charts (~44 KB)
│       └── build_report.py            # Injects data + JS into template → index.html
├── regenerate_results.py              # Retrain ML and refresh metrics
├── build_dashboard_data.py            # ★ Compute ALL dashboard series from real physics
└── config.py                          # Carrier / link / ML hyperparameters
```

## How to regenerate the dashboard

```bash
# 1. Create conda environment (Python 3.10-3.12 recommended)
conda create -n mmwave python=3.11 -y
conda activate mmwave

# 2. Install dependencies
pip install -r requirements.txt

# 3. Retrain ML models on the real dataset
python regenerate_results.py

# 4. Compute all derived series for the dashboard
python build_dashboard_data.py

# 5. Build the final HTML
python -m src.visualization.build_report

# 6. Open results/index.html in any browser
```

## Methodology notes

- **Temporal split**: Train/test split is chronological (first 80% for training,
  last 20% for testing) to prevent data leakage in time-series data.
- **38 GHz link**: ITU-R P.838-3 coefficients for 38 GHz (k=0.3282, α=0.9272).
- **Link distance**: 1.85 km (actual CoMMon link distance).
- **Class imbalance**: Dataset is ~74% Sunny, ~19% Cloudy, ~7% Rainy.

## Data provenance & honesty notes

- **Headline ML metrics** (RMSE / R² / MAE / latency) come straight from
  `regenerate_results.py` training on the **real measured** attenuation —
  not regenerated by the dashboard, never fabricated.
- **All derived curves** (BER-vs-SNR, SE-vs-attenuation, throughput, multi-band)
  use the project's own physics functions in `src/models/traditional.py`,
  `src/simulation/link_simulation.py`, and `src/models/beamforming.py`.
- **Lebanon map** is a transparent **model projection**: the CoMMon dataset
  has no geographic coordinates, so each city's attenuation/SNR/throughput
  is computed by evaluating the project's ITU-R P.838-3 + P.676 functions
  at that city's representative R₀.₀₁ rain rate (Lebanese climate gradient
  from the wet Mediterranean coast to the dry Bekaa rain-shadow).
